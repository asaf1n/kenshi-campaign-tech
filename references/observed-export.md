# Подтверждённые сведения о текущих выгрузках (не спецификация)

По ранее загруженным пользователем JSON из кампании обнаружены:

- корневое поле `format: "kenshi-session/10"`;
- `save.name`, `save.path`, `save.saved_at`, `save.kind`;
- `world.day`, `world.time`, `world.money`;
- вложенное `changes.format: "kenshi-session-diff/5"`;
- `changes.from`, `changes.to`, `changes.valid`, `changes.summary`, `changes.compared`;
- разделы diff: `roster`, `skills`, `equipment`, `prosthetics`, `inventory`, `health`, `supplies`, `world` (наличие и структура требуют проверки на реальных экспортах).

В наблюдавшихся примерах:

- экспорт 28 октября 2026, день 90;
- экспорт 30 октября 2026, день 108;
- экспорт 31 октября 2026, день 116, список персонажей с повторяющимся именем «Вьючный бык»;
- один из экспортов содержал `changes.summary.characters_after: 28`, `changes.valid: true`.

**Что не подтверждено:** местонахождение исходного кода конвертера, полная структура `kenshi-session/10`, гарантии стабильных ID персонажей, охват предметов/модов/мировых событий, корректность старого diff, возможность извлечения координат, правила обработки reload. Нет оснований утверждать, что предыдущие выгрузки полностью отражают сейв.

**Действие агента:** найти конвертер и несколько настоящих экспортов на ПК; провести инвентаризацию полей и тестов; собрать примерную сводку реального формата, не подменяя её новым схемным файлом. Старые файлы здесь не приложены, потому что исходные сырые байты библиотечного JSON не были доступны для переносимого вложения; этот стартовый комплект содержит только подтверждённую выдержку.
