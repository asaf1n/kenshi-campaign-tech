# Публикация скриншотов Kenshi и визуальный контекст чат-моделей

## 1. Назначение и концепция

Скриншоты игры Kenshi формируют хронологическую визуальную ленту игрового процесса для сопровождения кампаний чат-моделями (ChatGPT, Claude, Gemini).

**Ключевые принципы:**
- Скриншоты служат исключительно **визуальным контекстом**, а не источником извлечения игровых фактов.
- Модели самостоятельно анализируют изображения при обращении к ним в чате.
- Не применяется распознавание текста (OCR), классификация изображений, автоматическое создание записей хроники или подтверждение событий.
- Исходный игровой каталог скриншотов является **строго read-only**. Запрещено любое изменение, удаление или переименование оригиналов в `Kenshi/_screens`.

---

## 2. Источник и конфигурация

- **Стандартный каталог игры**: `<KENSHI_DIR>/_screens` (например, `C:\Program Files (x86)\Steam\steamapps\common\Kenshi\_screens`).
- **Переопределение источника**: переменная окружения `KENSHI_SCREENS_DIR` либо аргумент командной строки `--screens-dir`.
- **Поддерживаемые форматы**: `JPG`, `JPEG`, `PNG` (регистронезависимо).
- **Защита целостности**: файлы нулевого размера, файлы с повреждёнными сигнатурами (magic bytes) и файлы, находящиеся в процессе записи игрой в момент публикации, автоматически отбрасываются.

---

## 3. Политика 7-дневного скользящего окна

При каждом запуске публикации конвейер:
1. Вычисляет границу окна: `cutoff = now - 7 × 24 часа` в UTC.
2. Отбирает все изображения с временем изменения `mtime >= cutoff` (пограничное время ровно 7 суток включается).
3. Публикует **все** изображения в пределах окна без ручного отбора в оригинальном разрешении и качестве.
4. Исключает из новой публикации изображения старше 7 суток.
5. При ошибке чтения каталога публикация отменяется с сохранением предыдущей версии (защита от ошибочного удаления).
6. Если каталог существует, доступен и пуст, публикуется пустой индекс, а ранее опубликованные файлы очищаются.

## 4. Структура опубликованного пакета

```text
published/
├── manifest.json
├── current.json
├── changes.json
├── locations.json
├── world_reference.json
├── timeline.jsonl
├── brief.md
├── squad.md
└── screenshots/
    ├── index.json          # Машиночитаемый реестр kenshi-screenshots-index/1
    ├── index.md            # Хронологическая галерея со встроенными превью
    ├── screenshot_393.jpg  # Оригинальные изображения за последние 7 суток
    └── screenshot_394.jpg
```

## 5. Доступ чат-моделей к изображениям

| Модель / Среда | Механизм доступа | Особенности и ограничения |
|---|---|---|
| **ChatGPT** (GPT-4o, Web / Code Interpreter) | Прямой Raw URL: `https://raw.githubusercontent.com/asaf1n/kenshi-campaign-tech/main/published/screenshots/<filename>` | В веб-интерфейсе ChatGPT просмотр репозитория через GitHub connector ограничен текстом. Для визуального анализа модели передаётся прямой Raw URL либо изображение загружается через интерпретатор кода (Python PIL). |
| **Claude** (Claude 3.5 / 3.7 Sonnet, Opus) | Инлайн-галерея `screenshots/index.md` и Raw URL | GitHub Projects коннектор claude.ai индексирует текстовые файлы (Markdown, JSON). Просмотр изображений поддерживается в GitHub Web UI по превью в `index.md`. Для анализа в чате Claude обращается к Raw URL либо изображение передаётся в контекст локальным инструментом (Claude Code). |
| **Gemini** (Gemini 2.5/3.8 Flash, Pro, Antigravity) | Нативный мультимодальный контекст и Raw URL | В Antigravity и Gemini CLI инструмент чтения файлов (`read_file`) напрямую загружает изображение в контекст модели как бинарные токены. В веб-интерфейсе Gemini доступен анализ по прямой ссылке `raw.githubusercontent.com`. |

### Формат ссылок в индексе:
- **Прямой Raw URL**: `https://raw.githubusercontent.com/asaf1n/kenshi-campaign-tech/main/published/screenshots/<filename>` (HTTP 200, отдаёт бинарный поток `image/jpeg` или `image/png`).
- **Страница файла на GitHub**: `https://github.com/asaf1n/kenshi-campaign-tech/blob/main/published/screenshots/<filename>` (UI GitHub с возможностью масштабирования и метаданными).
- **Относительная ссылка Markdown**: `![filename](filename)` (автоматически рендерится в `index.md` при открытии в GitHub).

## 6. Команды запуска

```powershell
# Публикация скриншотов вместе с очередным обновлением состояния
python -m tools.campaign publish

# Публикация с явным указанием источника скриншотов
python -m tools.campaign publish --screens-dir "C:\Kenshi\_screens"

# Проверка схемы реестра скриншотов
python -m tools.campaign check-schemas

# Прогон автоматических тестов скриншотов
python -m unittest tests/test_screenshots.py
```
