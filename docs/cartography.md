# Картография

Производные геометрии мира для просмотрщика Kenshi-Compain (`sites/map/index.html`). Код: `tools/cartography.py`, тесты: `tests/test_cartography.py`.

## Входы и артефакты

| Объект | Расположение | Правило |
|---|---|---|
| Растр `areasmap.tga` (24-битный RGB, цвет = индекс `BIOME_GROUP`) | `data/world/<world_ref_id>.json`, `regions_map.rle` | Локальный, вне git. Не встраивается ни в один репозиторий |
| Контуры регионов | `assets/cartography/regions_map.svg` | Производный; хеш закреплён в `GEOMETRY_SVG_SHA256`. Идентификаторов регионов нет: регион задан `<title>Имя (name_en)</title>` |
| Таблица соседства | `assets/cartography/regions_adjacency.json` (`kenshi-region-adjacency/2`) | Производная от растра: граф `adjacency` и `border_lengths` (число пар пикселей 4-связности для каждой пары регионов, ключ `A\|B` по возрастанию `name_en`); хеши исходного растра, декодированных ячеек и таблицы; алгоритм `rle-four-neighbors/1` (`NONE` исключён, диагонали не считаются) |

Сопоставление регионов идёт по `name_en`/`sid`, не по русским строкам. `The Iron Trail` отображается как «Железный шельф».

## Коридоры

Цепочка — последовательность регионов, минимум два. Её задаёт пользователь в просмотрщике (последовательный выбор, добавление и удаление регионов); `CHAPTER_XI_CHAINS` — только примеры по умолчанию (`DEFAULT_CHAINS` в просмотрщике): А = Пойма → Возрождение → Окранова гордость → Скорняков край → Гиблые земли, Б = Пойма → Скрытый лес → Рука Окрана → Скорняков край → Гиблые земли. Шаг имеет статус `border` (общая граница в растре) и `border_length` (пар пикселей) или `gap` (длина 0). Цепочка не достраивается, линий между регионами нет, оценок проходимости и безопасности нет.

## Команды

```powershell
python -m tools.cartography --verify-geometry            # фикстурный режим: хеши SVG и таблицы; выпуск published/ проходит validate_release
python -m tools.cartography --verify-geometry --local    # локальный режим: пересчёт по data/world, world_source_verified=true
python -m tools.cartography --build-adjacency --world-source data/world/<world_ref_id>.json
```

Режим обязателен (`--verify-geometry` или `--build-adjacency`). Сводка для чата и SVG-экспорт карты формирует только просмотрщик `sites/map/index.html` (в конвертере их нет). Тексты статусов в просмотрщике: «в локации: Скуин», «рядом с локацией: Деревня Серодёров», «в регионе: Пурпурные пески»; в сводке группы с численностью, поимённо — персонажи вне основной группы, `ps:` — только у одноимённых.

## Доставка и совместимость просмотрщика

`deliver-companion` копирует оба артефакта в `docs/reference/` игрового репозитория в коммите выгрузки. Перед записью проверяется `sites/map/index.html` клона (`check_viewer_compat`): граф, длины границ, контуры, примеры цепочек (`DEFAULT_CHAINS`) и `world_ref_id` просмотрщика совпадают с артефактами, редактор цепочек присутствует (в том числе правило «минимум два региона»), растра и формулировок о проходимости нет, по умолчанию загружается `../../published/`, замена выпуска требует `confirm`. Состояние карты отражает отдельное поле отчёта `cartography`: `ok` (артефакты доставлены или не изменились; `cartography_changed` показывает запись), `incompatible` (просмотрщик несовместим или не читается; артефакты не записаны) или `skipped` (каталог назначения или файл - ссылка либо запись не выполнялась; это не ошибка доставки); причина в `cartography_reason`. При `incompatible` и `skipped` ранее доставленные `regions_*` остаются в клоне и входят в коммит как есть. `status=failed` означает только сбой доставки `published/`. Отсутствие просмотрщика в клоне ошибкой не является: проверка совместимости пропускается, артефакты записываются, `cartography=ok`.

## Проверка

`python -m unittest tests.test_cartography` (`KENSHI_COMPANION_DIR` — клон Kenshi-Compain; при наличии `node` исполняется логика просмотрщика: `chain-logic` и `summary-logic`, в том числе сводка, подписи типов и склонение). Фикстурный режим (CI) не требует `data/world` и `published/`; локальные классы пропускаются без них.
