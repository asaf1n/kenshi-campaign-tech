# Настройки, параметры симуляции и конфигурация Kenshi

Документ описывает структуру, источники и семантику настроек Kenshi на всех уровнях игры: от низкоуровневой конфигурации графического движка и файлов клиента до параметров сложности в сохранениях, боевых режимов персонажей и базовых констант Forgotten Construction Set (FCS).

## 1. Многоуровневая архитектура параметров

В Kenshi параметры конфигурации и симуляции разделены на 4 изолированных слоя:

```text
+-----------------------------------------------------------------------------------+
| 1. Конфигурация клиента и движка (Локальные текстовые файлы INI/CFG в корне игры) |
|    - settings.cfg   : глобальные множители мира, рейдов, ИИ, пути сейвов, видео/звук  |
|    - kenshi.cfg     : подсистема рендеринга Ogre3D, Direct3D11, разрешение, VSync    |
|    - controls.cfg   : привязка клавиш, горячие команды, сервисные инструменты        |
|    - screens.cfg    : порядковый счетчик скриншотов F8                              |
+-----------------------------------------------------------------------------------+
                                         |
+-----------------------------------------------------------------------------------+
| 2. Состояние кампании / сохранения (Бинарный quick.save, запись типа 56)           |
|    - Ползунки сложности (float): шанс смерти (cod), урон (gdm), голод (ht) и др.   |
|    - Глобальные тумблеры ИИ (bool): автолечение, дележ едой, сброс ресурсов и др.  |
|    - Организация отряда: построение (formation), версия движка, активный этаж      |
+-----------------------------------------------------------------------------------+
                                         |
+-----------------------------------------------------------------------------------+
| 3. Тактические режимы персонажей (Бинарные platoon/*.platoon, запись типа 36)     |
|    - Боевые стойки: насмешка (taunt), оборона (defensive), пассивный, дальний бой |
|    - Статусы поведения: скрытность (stealth), переноска (carrying), погоня        |
+-----------------------------------------------------------------------------------+
                                         |
+-----------------------------------------------------------------------------------+
| 4. Базовые константы игрового баланса (FCS gamedata.base / fcs.def, запись типа 0)|
|    - Боевые лимиты: attack slots, шанс блока, урон органам, кровотечение          |
|    - Физика и мир: дни в году, цикл день/ночь, базовая грузоподъемность, опыт     |
+-----------------------------------------------------------------------------------+
```

## 2. Конфигурация клиента (`<Kenshi_Root>/`)

### 2.1. `settings.cfg` — параметры симуляции, геймплея и клиента

Файл `settings.cfg` расположен в корне установки Kenshi (`C:\Program Files (x86)\Steam\steamapps\common\Kenshi\settings.cfg`) и содержит ключевые глобальные параметры, определяющие поведение игрового мира, генерацию NPC, сложность набегов и пути файловой системы.

#### Параметры сложности и симуляции мира

| Параметр | Тип | Пример | Значение по умолчанию | Описание и влияние на механику |
|---|---|---|---|---|
| `Squad size multiplier` | float | `2.0` | `1.0` | Множитель размера отрядов NPC в мире. Увеличивает количество бойцов в бродячих группах бандитов, патрулях фракций и стаях животных. |
| `Global population multiplier` | float | `3.0` | `1.0` | Глобальный множитель плотности населения. Регулирует частоту появления и количество активных отрядов на бесшовной карте. |
| `attacks` | int | `2` | `1` | Количество одновременных слотов атаки (Attack Slots) в ближнем бою. Значение `1` означает дуэльный бой (противники ждут очереди); `2` и более позволяют нескольким врагам наносить удары по одной цели синхронно, резко повышая летальность численного превосходства. |
| `raidSizeMult` | float | `2.5` | `1.0` | Множитель численности нападающих во время рейдов (набегов) на аванпосты и базы игрока. |
| `raidFrequencyMult` | float | `1.5` | `1.0` | Множитель частоты рейдов. Значения выше `1.0` сокращают интервал между карательными экспедициями и нападениями бандитов. |
| `Dismemberment` | int | `1` | `1` | Механика расчленения (потери конечностей): `0` = Never (никогда, конечности остаются изувеченными); `1` = Rare (только при ударе с переходом урона ниже критического порога выживания); `2` = Frequent (конечность отсекается при любом уроне ниже -100 HP). |
| `Blood` | int (bool) | `1` | `1` | Включение декалей и брызг крови при получении режущего урона (`0`/`1`). |
| `civilians` | int (bool) | `1` | `1` | Спавн мирных жителей и ремесленников в городах (`0`/`1`). |
| `censorship` | int (bool) | `0` | `0` | Цензура наготы моделей персонажей (`0` = отключена, `1` = включена). |
| `harpoonLimit` | int | `60` | `60` | Ограничение максимального количества турелей/гарпунов на территории базы. |
| `Fast zone hopping` | int (bool) | `1` | `1` | Оптимизация быстрой подгрузки секторов мира при переключении фокуса камеры между удаленными персонажами игрока. |

#### Хранение сохранений и служебные параметры

| Параметр | Тип | Значение | Описание и значение для конвейера |
|---|---|---|---|
| `User save location` | int (bool) | `1` | **Критический параметр размещения сейвов**. При `1` сохранения пишутся в `%LOCALAPPDATA%\kenshi\save` (во избежание проблем с правами доступа Windows UAC). При `0` — в подпапку `save\` внутри каталога установки игры. Модуль [`tools.config.Config`](file:///c:/Users/artem/kenshi-campaign-tech/tools/config.py) и [`tools.locator`](file:///c:/Users/artem/kenshi-campaign-tech/tools/locator.py) учитывают оба пути с приоритетом `LOCALAPPDATA`. |
| `Auto save` | int (bool) | `1` | Включение периодического автосохранения (`0` / `1`). |
| `Auto save time (minutes)` | int | `3` | Интервал между автоматическими сохранениями в минутах. |
| `autosaveindex` | int | `0` | Циклический счетчик файла автосохранения (`autosave0`, `autosave1`, `autosave2`). |
| `continue` | string | `hot lon` | Имя папки сохранения, используемое для кнопки «Продолжить» в главном меню игры. |

| Параметр | Тип | Пример | Описание |
|---|---|---|---|
| `language` | string | `ru_RU` | Языковой пакет игрового интерфейса и диалогов. |
| `steam_language` | string | `english` | Язык клиента Steam. |
| `Show names` | int (bool) | `1` | Отображение имен персонажей над их моделями в 3D-мире. |
| `floaters` | int (bool) | `1` | Всплывающий текст урона, лечения и набора опыта над персонажами. |
| `font size2` | int | `4` | Индекс масштабирования шрифта интерфейса. |
| `camera speed`, `camera zoom` | float | `558.65`, `160.0` | Скорость панорамирования и шаг приближения свободной камеры. |
| `Rotation marker`, `Movement marker`| int (bool) | `0`, `1` | Отображение маркеров назначения и вращения при отдаче приказов кликом мыши. |

> [!NOTE]
> Изменение параметров `Squad size multiplier`, `Global population multiplier` и `attacks` требует перезапуска игры и/или переноса (импорта) сохранения («Import Game»), чтобы новые лимиты популяции вступили в силу для уже сгенерированных зон.

### 2.2. `kenshi.cfg` — параметры графического ядра Ogre3D

Файл содержит настройки графической подсистемы рендеринга `Direct3D11 Rendering Subsystem`:

- `Video Mode`: целевое экранное разрешение, частота обновления и глубина цвета (например, `2880 x 1800 @ 32-bit colour [0]`).
- `Full Screen`: режим полного экрана (`Yes` / `No`).
- `VSync`, `VSync Interval`: синхронизация кадров с разверткой дисплея (`Yes`, `1`).
- `FSAA`: уровень сглаживания (Full Scene Anti-Aliasing, `1` = выкл, `2`, `4`, `8`).
- `Driver type`: `Hardware` (аппаратное ускорение видеокарты).
- `Rendering Device`: имя активного графического адаптера (например, `AMD Radeon(TM) 880M Graphics`).

### 2.3. `controls.cfg` — привязка клавиш и режимы управления

Конфигурационный файл биндингов клавиатуры и мыши. Включает привязки для ключевых игровых механик, тактических команд и сервисных режимов:

- **Камера и движение**: W/A/S/D, поворот Q/E, наклон `,` / `.`, зум Home/End.
- **Управление временем**: `Space` / `F1` (Пауза), `F2` (1x нормальная скорость), `F3` (2x ускоренная), `F4` (3x максимальная), `F5` (Quicksave), `F9` (Quickload).
- **Выбор и группы**: `1`..`0` (выбор членов отряда), `GRAVE` (тильда `~` — выбрать всех), `Tab` (смена активного отряда), `[` и `]` (предыдущий/следующий персонаж).
- **Быстрые приказы и режимы боя (NumPad)**:
  - `NUM0` (`toggle_block`): временный режим блока (персонаж держит защиту).
  - `NUM1` (`toggle_hold`): удержание позиции (запрет автоматического преследования).
  - `NUM2` (`toggle_passive`): пассивный режим (не атаковать без прямого приказа).
  - `NUM3` (`toggle_ranged`): дальний бой (разрешение стрельбы из арбалета).
  - `NUM4` (`toggle_sneak`): скрытность / перемещение ползком.
  - `NUM5` (`toggle_taunt`): провокация / насмешка (привлечение агро врагов).
  - `NUM6` (`cycle_run_speed`): переключение скорости передвижения (ходьба, бег, спринт, подстройка под медленного).
  - `NUM7` (`medic`): команда оказания первой помощи (медик).
  - `NUM8` (`rescue`): команда спасения и эвакуации раненого союзника.
- **Сервисные и отладочные инструменты движка**:
  - `Shift+F12` (`editor_toggle`): встроенный редактор мира и построек FCS In-game.
  - `Ctrl+Shift+F11` (`rebuild_navmesh`): перерасчет навигационной сетки (Navmesh) текущего сектора при застревании NPC.
  - `Ctrl+F6` (`reload_biomes`): горячая перезагрузка данных биомов.
  - `F8` (`screenshot`): снимок экрана без интерфейса (увеличивает счетчик в `screens.cfg`).

### 2.4. `screens.cfg` — трекер скриншотов

Содержит единственное поле `count=<N>` (например, `count=372`). Движок Kenshi читает это значение при запуске и сохраняет снимки экрана по нажатию `F8` в формате `screenshot_<000N>.png`, увеличивая счетчик на единицу при каждом вызове.

## 3. Настройки кампании в сохранении (`quick.save`)

Настройки конкретного прохождения фиксируются в файле `quick.save` в бинарной записи с кодом типа `56` (`GAME_STATE` / `WORLD_STATE`).

### 3.1. Ползунки сложности (Gameplay Float Multipliers)

Значения задаются игроком в меню «Расширенные настройки» (Advanced Options) при старте новой игры или при процедуре импорта сохранения. Сохраняются в словаре `float` записи типа `56`:

| Ключ FCS | Полное наименование | Диапазон | По умолчанию | Описание и влияние на баланс |
|---|---|---|---|---|
| `cod` | Chance of Death | 0.1 – 4.0 | `1.0` | **Шанс смерти**. Масштабирует скорость ухудшения состояния кровоточащих ран и время, за которое персонаж в критическом бессознательном состоянии истекает кровью. Высокие значения делают ранения летальными за считанные игровые минуты. |
| `gdm` | Global Damage Multiplier | 0.1 – 4.0 | `1.0` | **Глобальный множитель урона**. Прямой скаляр для всего наносимого режущего и тупого урона в рукопашном и дальнем бою. При значении `2.0` бои становятся вдвое быстрее и фатальнее. |
| `ht` | Hunger Time | 0.1 – 5.0 | `1.0` | **Множитель времени голодания**. Обратный коэффициент скорости расхода сытости: значение `1.0` соответствует базовому потреблению; значения меньше `1.0` ускоряют появление голода, требуя больше запасов провизии. |
| `bs` | Building Speed | 0.1 – 5.0 | `1.0` | **Скорость строительства**. Масштабирует скорость возведения каркасов зданий, укреплений и верстаков строителями. |
| `ps` | Production Speed | 0.1 – 5.0 | `1.0` | **Скорость производства**. Ускоряет переработку ресурсов, ковку оружия, пошив брони и фермерство на станках. |
| `rs` | Research Speed | 0.1 – 5.0 | `1.0` | **Скорость исследований**. Масштабирует скорость изучения технологий на исследовательских стендах. |
| `nnm` | Number of Nests Multiplier | 0.25 – 4.0 | `1.0` | **Множитель количества гнезд и лагерей**. Регулирует число спавнящихся на глобальной карте гнезд животных (клювотварей, пауков) и постоянных стоянок бандитов. |

> [!IMPORTANT]
> Данные множители хранятся непосредственно в сохранении. Если игрок изменяет параметры при импорте сейва, они перезаписываются в записи типа `56` и остаются неизменными до следующего импорта.

### 3.2. Глобальные тумблеры ИИ отряда (Squad AI Toggles)

Управляют автоматическим поведением фракции игрока (соответствуют вкладке «ИИ / AI» в окне отряда в игре). Сохраняются в словаре `bool` записи типа `56`:

| Ключ | Чекбокс в интерфейсе Kenshi | Значение в кампании | Описание функционала |
|---|---|---|---|
| `share` | Share food | `True` | **Делиться едой**. Персонажи автоматически берут провизию из рюкзаков сопартийцев в радиусе досягаемости при падении уровня голода. |
| `ditch` | Ditch resources | `False` | **Складывать ресурсы**. Рабочие автоматически относят произведенную продукцию и добытую руду в соответствующие целевые хранилища при заполнении внутреннего инвентаря станка. |
| `feed` | Feed animals | `True` | **Кормить животных**. Персонажи автоматически подкармливают прирученных животных (вьючных быков, гарру) из своих рюкзаков. |
| `heal` | Medic | `False` | **Автоматическое лечение**. Свободные от задач персонажи с аптечками в инвентаре автоматически оказывают медицинскую помощь раненым союзникам. |
| `rescue` | Rescue | `False` | **Автоматическое спасение**. Члены отряда автоматически подбирают находящихся без сознания союзников и относят их в свободные кровати или спальные мешки. |
| `sit` | Sit when idle | `True` | **Сидеть при бездействии**. Персонажи без назначенных задач автоматически садятся на ближайшие стулья, лавки или подушки. |
| `sleep` | Sleep when wounded | `True` | **Спать при ранении**. Тяжело раненные члены отряда самостоятельно ложатся в свободные кровати для ускорения регенерации. |
| `shootfirst` | Ranged: Shoot first | `False` | **Дальний бой: стрелять первыми**. Стрелки и турельщики открывают огонь по потенциально враждебным или нейтральным приближающимся целям без ожидания ответной агрессии. |
| `help` | Help allies | `False` | **Помогать союзникам**. Персонажи автоматически вмешиваются в бой на стороне союзных фракций, если видят нападение на них. |
| `stay` | Hold / Stay put | `False` | **Удерживать позицию**. Глобальный запрет для всего состава на перемещение при преследовании убегающих врагов. |
| `bl` | Block | `True` | **Режим блока**. Глобальный флаг режима защиты отряда. |
| `eject` | Eject items | `True` | **Сброс излишков**. Автоматический выброс предметов, не помещающихся в переполненные склады. |
| `ep` | Easy prospecting | `False` | **Упрощенная геологическая разведка**. Снижение требований к навыкам при сканировании ресурсов почвы. |

### 3.3. Структура отряда и метаданные мира

Запись типа `56` в `quick.save` также фиксирует системные параметры управления отрядами:

- `formation` (`int`): выбранный тип построения отряда при совместном движении:
  - `0` = `SquadFormation.RANDOM` (свободное перемещение группой);
  - `1` = `SquadFormation.CARAVAN` (движение колонной друг за другом, караван);
  - `2` = `SquadFormation.MILITARY` (военный строй шеренгой с удержанием интервала).
- `floor num` (`int`): текущий активный этаж зданий для фильтрации отображения интерьеров на экране.
- `version` (`string`): версия движка Kenshi, записавшая сохранение (например, `"1.0.68"`).
- `pfaction name` (`string`): пользовательское имя фракции игрока.

## 4. Тактические режимы персонажей (`platoon/*.platoon`)

В файлах отрядов `platoon/*.platoon` для каждого персонажа игрока создается запись состояния типа `36` (`CharacterState`). В ней хранятся индивидуальные тактические стойки и боевые режимы:

| Поле типа 36 | Тип | Назначение и боевое влияние |
|---|---|---|
| `taunt mode` | bool | **Насмешка / Провокация**. Персонаж активно провоцирует противников, привлекая вражеское агро на себя. Используется «танками» в тяжелой броне для защиты стрелков и ремесленников. |
| `defensive mode` | bool | **Оборона**. Персонаж получает бонус `+20` к защите в ближнем бою (Melee Defence), но полностью прекращает инициировать собственные атаки, только блокируя и парируя удары. |
| `passive mode` | bool | **Пассивный режим**. Персонаж не вступает в бой по собственной инициативе и игнорирует происходящие вокруг сражения, пока не получит прямой приказ игрока либо не будет атакован непосредственно. |
| `ranged mode` | bool | **Дальний бой**. Разрешает использование дальнобойного оружия (арбалетов). При выключенном флаге персонаж убирает арбалет и сражается только в ближнем бою. |
| `chase mode` | bool | **Погоня**. Персонаж преследует убегающих противников за пределами зоны непосредственного контакта. При отключении — останавливается после разрыва дистанции. |
| `non combat mode` | bool | **Мирный режим**. Персонаж избегает любого боевого контакта, пытаясь разорвать дистанцию. |
| `stealth` | bool | **Скрытность**. Персонаж передвигается в режиме скрытности (на корточках), развивая навык скрытности и пытаясь остаться незамеченным. |
| `carrying` | bool | **Переноска**. Персонаж несет на плече другого персонажа, союзника, пленника или тушу животного (снижает скорость и боеспособность). |

## 5. Базовые константы игрового баланса FCS (`fcs.def`)

Базовые константы симуляции Kenshi компилируются в мастер-файл `gamedata.base` и определяются спецификацией `fcs.def` (тип записи `0`, `GLOBAL_SETTINGS`):

## 6. Взаимосвязь настроек с конвейером `kenshi-campaign-tech`

1. **Обнаружение и валидация путей сохранений**:
   - Параметр `User save location` из `settings.cfg` определяет физическое размещение сейвов. Класс [`tools.config.Config`](file:///c:/Users/artem/kenshi-campaign-tech/tools/config.py) настраивает порядок обхода директорий: в первую очередь проверяется `%LOCALAPPDATA%\kenshi\save`, во вторую — `<Kenshi_Root>\save`.

2. **Извлечение данных в `tools.save_reader`**:
   - При парсинге `quick.save` считывается запись типа `56`, откуда берутся не только игровое время (`time day/hour/minute`) и деньги (`player money`), но и параметры сложности `cod`, `gdm`, `ht`, `bs`, `ps`, `rs`, `nnm`, а также флаги поведения ИИ.
   - При разборе файлов взводов `.platoon` из записи типа `36` извлекаются тактические стойки персонажей (`taunt mode`, `defensive mode`, `passive mode`, `ranged mode`), необходимые для планирования боевых задач.

3. **Формирование контекста для ChatGPT**:
   - Для тактического анализа в ChatGPT Project критически важно знать действующие множители мира:
     - При множителе численности отрядов `Squad size multiplier = 2` и популяции `3` стандартные группы бандитов насчитывают по 30–50 бойцов вместо обычных 15, что требует осторожной стратегии кайтинга и применения арбалетов.
     - Значение `attacks = 2` (слоты атаки) исключает выживание одиночного бойца в плотном окружении, делая обязательным использование танков в режиме `taunt mode` и бойцов прикрытия в `defensive mode`.
     - При `cod = 1.0` и `gdm = 1.0` критические ранения требуют немедленной стабилизации аптечками, что делает настройки ИИ `share` и `heal` жизненно важными для предотвращения гибели участников экспедиции.
