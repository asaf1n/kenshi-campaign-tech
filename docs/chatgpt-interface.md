# Чат-ИИ модели (LLM ассистенты) как интерфейс кампаний

## Основной сценарий

Универсальная инструкция — `prompts/03-CHATGPT-INSTRUCTIONS.md`; каноническое хранилище — GitHub-репозиторий `asaf1n/kenshi-campaign-tech`. Активная кампания выбирается по запросу пользователя. Все её авторские данные хранятся в `Campaign/<campaign_name>/`; общие инструкции и документация не привязываются к именам персонажей, историям и текущему состоянию отдельных прохождений.

Чат-ИИ ассистент читает необходимые авторские документы кампании из одного актуального Git-коммита. Для числового состояния отдельно читает `published/manifest.json`, проверяет принадлежность публикации активной кампании, `snapshot_id`, `branch_id`, `generated_at` и `validation.status`. Связанные артефакты `published/` читаются из того же коммита. Если принадлежность или актуальность не доказаны, публикацию не выдавать за текущее состояние.

## Авторские документы

В `Campaign/<campaign_name>/` находятся подтверждённая хроника, история персонажей и согласованные билды, текущие планы и открытые решения, а также методика ответа, если она нужна этой кампании. Набор файлов определяется фактическим содержимым папки; не переносить данные одной кампании в другую. В общих файлах хранить только универсальные правила, интерфейсы и контракты.

## Запись и доставка

Подтверждённые изменения авторских файлов записываются непосредственно в GitHub по существующим путям. Перед записью проверяй редакцию и состав изменений, после — коммит и удалённое чтение. Прямой GitHub commit уже является доставкой; отдельный локальный push не требуется. Если использован локальный клон, проверенные и подтверждённые изменения коммитятся и отправляются обычным push автоматически, без повторного запроса.

`published/` формируется техническим конвейером после проверки, не редактируется вручную из игрового Chat. Для доступа к локальному сейву требуется отдельная задача, реальная доступность среды и соблюдение `AGENTS.md`. GitHub-доступ не равен доступу к игровому ПК. При недоступности GitHub возможна резервная ручная загрузка пакета, но она не подтверждает обновление репозитория.

Project Sources, Library и вложения беседы не являются автоматически синхронизированными копиями GitHub. Не выдавай запись в одном хранилище за запись в другом.

## Представления

1. Сводка игрового состояния на проверенную контрольную точку.
2. Отряд — устойчивые ID, навыки, здоровье, экипировка и роли.
3. Прогресс — сравнение совместимых снимков с границами периода и ограничениями diff.
4. Хроника — подтверждённые события отдельно от гипотез и художественного текста.
5. Планирование — варианты маршрутов и открытые решения, не объявляемые завершёнными.

Графики и таблицы применяются по задаче. Подтверждённые авторские изменения отражаются в `Campaign/<campaign_name>/`; `published/current.json` вручную не изменяется.
