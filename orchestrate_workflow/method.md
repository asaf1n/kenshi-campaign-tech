# Привязка проекта Kenshi Campaign

Используется установленный комплект `asaf1n/AI-Orchestrated-Workflow`, ветка `main`: `orchestrate`, `planner`, `implementer`, `reviewer`. Глобальные навыки и общие формы **не копируются** в проект. При отсутствии установленного/доступного навыка сообщи об этом и работай по явно согласованному локальному плану; не выдавай симуляцию навыка за его запуск.

## Предметные источники

| Назначение | Путь |
|---|---|
| Контракт репозитория | `AGENTS.md` |

## Пути оркестрации (только при использовании установленного workflow)

| Назначение | Путь |
|---|---|
| План и очередь | `orchestrate_workflow/plans/<plan>/00_summary.md` |
| Задания | `orchestrate_workflow/plans/<plan>/<task>.md` |
| Локальная сессия | `orchestrate_workflow/<plan>/spec.md`, `result.md`, `review.md` |
| Ревью плана | `orchestrate_workflow/<plan>/review_plan.md` |

`plans/` коммитится; локальные сессии исключаются по точному пути через `.git/info/exclude`. Не придумывай дополнительную иерархию для протокола, не дублируй формы. При использовании `/orchestrate` сначала проверяй установленную версию навыка и фактическое обнаружение его средой. Новый план — сначала независимое ревью и явное утверждение; запуск исполнения — отдельное действие. Исполнители не коммитят; коммит принятых этапов — оркестратор; push — только по отдельному разрешению.

## Инструменты и внешние вызовы

- Claude Code CLI (версия 2.1.289) подтверждён локально и назначен внешним независимым рецензентом (`reviewer`) для верификации диффов и архитектурных инвариантов. Вызов выполняется через неинтерактивный канал `$null | claude -p --permission-mode plan`.
- Antigravity выступает в качестве оркестратора (`orchestrate`) и среды исполнения (`implementer` через встроенный субагент `self`).

## Известные неизвестные

- Путь к рабочему конвертеру и его исходникам не указан; найти на ПК, не предполагать наличие в новой папке.
- Реальные каталоги сейвов, скриншотов, используемые моды и список поддерживаемых полей проверяются на месте.
- Возможность чтения приватного GitHub-репозитория чат-ИИ моделями должна быть проверена на реальном подключении.
- Верифицированные команды тестов появятся после инвентаризации; не выдавать предполагаемые команды за проверенные.
