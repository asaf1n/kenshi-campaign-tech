# 02-ocr-suppression-and-cleanup: Подавление пустых OCR-артефактов

## Цель
Устранить неоправданный расход контекста LLM (~235 тыс. токенов) на пустые OCR-выгрузки. При отсутствии распознанного текста интерфейса не публиковать `feed.md`, `index.md` и `annotations.jsonl`, оставляя только компактный `index.json`, и очищать устаревшие артефакты при доставке.

## Решения
- 2026-11-03. В текущем релизе OCR распознал 0 из 343 кадров (`provenance.source = metadata`), породив 4 избыточных представления почти без смысловой информации.
- 2026-11-03. Определение полезного OCR опирается на фактические поля контракта `ocr` (`tools/screenshot_extractor.py`): `dialogues`, `characters`, `location`, `notifications`, `items_or_tasks`. Если во всех кадрах выпуска эти поля пусты или `null`, разметка признается неинформативной.
- 2026-11-03. При отсутствии содержательного OCR публикатор подавляет генерацию `feed.md`, `index.md` и `annotations.jsonl`, а также исключает опциональные ключи `screenshot_annotations` и `screenshot_feed` из `manifest.json["artifacts"]`.
- 2026-11-03. Утилита доставки `deliver_companion.py` дорабатывается: при переносе в `Kenshi-Compain` удаляются файлы, отсутствующие в свежей публикации, предотвращая накопление устаревших артефактов в игровом репозитории.

## Этапы задачи

1. **Критерий содержательности OCR и подавление публикации (`tools/publisher.py`)**. Реализовать проверку полей `ocr` (`dialogues`, `characters`, `location`, `notifications`, `items_or_tasks`). При нулевом полезном выходе исключать `feed.md`, `index.md`, `annotations.jsonl` из публикации и из `manifest.json["artifacts"]`. Готово: при отсутствии OCR файлы разметки не создаются, `index.json` публикуется в минимальном виде. Не начат.
2. **Очистка устаревших артефактов при доставке (`tools/deliver_companion.py`)**. Добавить в `deliver_companion.py` удаление из целевого каталога `published/screenshots/` тех файлов (`feed.md`, `index.md`, `annotations.jsonl`), которые были исключены из текущей публикации. Готово: доставка в `Kenshi-Compain` очищает неактуальные артефакты. Не начат.
3. **Регрессионные тесты и валидация (`tests/test_screenshot_annotations.py`, `tests/test_screenshots.py`, `tests/test_publish.py`)**. Покрыть сценарий подавления пустых артефактов тестами и проверить валидацию манифеста. Готово: тесты проходят. Не начат.
