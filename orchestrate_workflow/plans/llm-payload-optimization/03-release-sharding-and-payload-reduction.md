# 03-release-sharding-and-payload-reduction: Очистка и шардирование current.json, концепция chat-pack

## Цель
Сократить размер снимка отряда и мира `current.json` (сейчас ~1 МБ, 335 тыс. токенов), устранив дублирование сырых структур `raw`, `hidden_stats_raw` и дефолтных навыков на 1.0 (экономия ~240 тыс. символов / −22%). Разделить срез на слои публикации (L0: brief, L1: squad, L2: шарды `characters.json`, `bases.json`, `world_state.json`) и подготовить экспорт легковесного `chat-pack/` для веб-чатов.

## Решения
- 2026-11-03. В `current.json` поле `items[].raw` дублирует нормализованные параметры (`name`, `inventory_coords`, `slot`). Его исключение снижает объем без потери информации.
- 2026-11-03. Навыки персонажей со значением по умолчанию 1.0 не несут ценности для планирования и тактики компаньона, но создают сотни строк шума на каждого бойца. В опубликованном росторе указывать только фактически прокачанные навыки (>1.0).
- 2026-11-03. Для чтения LLM монолитный 1 МБ файл неэффективен. Шардирование на `current/characters.json`, `current/bases.json`, `current/world_state.json` позволяет агентам подгружать только нужный срез.
- 2026-11-03. Для веб-интерфейсов (Gemini, ChatGPT, Claude) предусмотреть сборку пакета `chat-pack/` (сводка `context.md` <=40k токенов, 10–20 ключевых кадров, `manifest.json`).

## Этапы задачи

1. **Очистка сериализации снимка (`tools/session_export.py`, `tools/save_reader.py`)**. Исключить поле `raw` у предметов инвентаря в публикации, скрыть `hidden_stats_raw` и фильтровать навыки со значением 1.0 при экспорте опубликованного JSON. Готово: объем `current.json` сокращается на 20–25%, проверка схем `contracts/session.schema.json` проходит. Не начат.
2. **Шардирование среза текущего состояния (`tools/publisher.py`)**. Добавить формирование каталога `published/current/` с отдельными файлами `characters.json`, `bases.json`, `world_state.json` (без технических хэндлов). Сохранить очищенный монолитный `current.json` в корне публикации для обратной совместимости. Готово: файлы шардов создаются и соответствуют данным монолита. Не начат.
3. **Генерация легковесного chat-pack (`tools/deliver_companion.py`, `tools/campaign.py`)**. Реализовать формирование вспомогательного бандла `chat-pack/` с объединенным файлом `context.md` (brief + squad + changes + контрольная точка арки, <=40 тыс. токенов) для быстрой ручной загрузки в чат-проекты. Готово: команда `python -m tools.campaign build-chat-pack` формирует архив/папку в пределах лимитов веб-чатов. Не начат.
4. **Тесты и верификация**. Обновить `tests/test_publish.py` и `tests/test_contracts.py` с проверкой шардов и чистоты `current.json`. Готово: тесты проходят. Не начат.
