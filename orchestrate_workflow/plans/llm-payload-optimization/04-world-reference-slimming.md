# 04-world-reference-slimming: Облегчение справочника мира

## Цель
Сократить размер справочника `published/world_reference.json` с 650 тыс. символов до семантического минимума (<150 тыс. символов), исключив из публикуемой проекции тяжелый RLE-растр `regions_map` (420 тыс. символов), сохранив неизменяемый полный кэш для инженерных утилит и публикуя справочник только при смене `world_ref_id`.

## Решения
- 2026-11-03. Для LLM растровый массив `regions_map` (65536 значений RLE) не несет пользы и перегружает контекст. Моделям необходимы семантические описания: регионы, биомы, опасности, города, фракции.
- 2026-11-03. Инженерный локатор (`tools/locator.py`) производит пространственное разрешение зон по полному кэшу справочника из `data/cache/` (адресуемому по `world_ref_id`), не завися от содержимого публичного файла.
- 2026-11-03. Облегчение оформляется как публикационная проекция: полный файл с исходными `source_hashes` и `regions_map` сохраняется в неизменяемом кэше по `world_ref_id`, а в `published/world_reference.json` выгружается семантическая часть. В схеме `contracts/world-reference.schema.json` поле `regions_map` делается опциональным.
- 2026-11-03. Публикация справочника пропускается при неизменности `world_ref_id` между релизами.

## Этапы задачи

1. **Публикационная проекция справочника мира (`tools/publisher.py`)**. Реализовать проекцию для публикации: исключение `regions_map` при формировании `published/world_reference.json`. Полный кэшированный файл в `data/cache/` остается без изменений. Готово: объем `published/world_reference.json` сокращается более чем на 70%. Не начат.
2. **Адаптация схемы и валидатора (`contracts/world-reference.schema.json`, `tools/validation.py`)**. Сделать поле `regions_map` опциональным в схеме `contracts/world-reference.schema.json`. Обновить валидатор `validate_world_reference`, чтобы он проверял RLE-сегменты только при их наличии в объекте. Готово: валидация опубликованного справочника проходит успешно. Не начат.
3. **Изоляция локатора (`tools/locator.py`)**. Убедиться, что `locator.py` загружает полный справочник из кэша по `world_ref_id` и сохраняет точность пространственной привязки. Готово: тесты `tests/test_locations.py` проходят. Не начат.
4. **Тесты и регрессионный прогон**. Проверить поведение конвейера при сборке и публикации справочника. Готово: `python tests/run_evidence.py` подтверждает успешность проверок. Не начат.
