# 04-world-reference-slimming: Облегчение справочника мира

## Цель
Сократить размер справочника `world_reference.json` с 650 тыс. символов до семантического минимума, вынеся тяжелый RLE-растр карты регионов `regions_map` (420 тыс. символов) и контрольные суммы `source_hashes` (81 тыс. символов) в отдельный технический файл геометрии, и публиковать справочник только при изменении `world_ref_id`.

## Решения
- 2026-11-03. Для языковых моделей растровый RLE-массив `regions_map` бесполезен: LLM не декодирует 65536 пикселей на лету, ей нужны названия регионов, биомы, опасности, города и фракции.
- 2026-11-03. RLE-растр необходим инженерному локатору (`tools/locator.py`) для определения зоны по координатам (x, z). Локатор может читать технический файл `world_geometry.json` (или загружать его из кэша данных).
- 2026-11-03. Справочник мира статичен между игровыми сессиями и меняется только при смене сборки модов. Нет необходимости дублировать его тяжелую копию в каждый релиз при неизменном `world_ref_id`.

## Этапы задачи

1. **Разделение структур справочника мира (`tools/world_worker.py`, `tools/world_reference.py`)**. Сохранять семантическую часть (регионы, зоны, поселения, фракции, погода) в `world_reference.json`, а математический растр `regions_map` и `source_hashes` — в `world_geometry.json`. Готово: `world_reference.json` уменьшается более чем на 75%. Не начат.
2. **Адаптация локатора (`tools/locator.py`)**. Обеспечить бесшовную работу `resolve_locations`: если `regions_map` отсутствует в `world_reference.json`, локатор подгружает его из `world_geometry.json` или директории кэша мира. Готово: тесты локатора `tests/test_locations.py` проходят успешно. Не начат.
3. **Обновление контрактов и валидатора (`contracts/world-reference.schema.json`, `tools/validation.py`)**. Сделать `regions_map` опциональным в схеме `world-reference.schema.json` или выделить схему для геометрии. Адаптировать `validate_world_reference`. Готово: валидация проходит. Не начат.
4. **Оптимизация публикации (`tools/publisher.py`)**. В `published/` публиковать облегченный `world_reference.json`. При неизменном `world_ref_id` не перезаписывать файл попусту. Готово: `run_evidence.py` подтверждает корректность публикации. Не начат.
