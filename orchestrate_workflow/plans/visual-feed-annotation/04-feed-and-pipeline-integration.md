# Задача 04: Хронологическая лента feed.md и интеграция в конвейер

## Цель
1. Создать генератор русскоязычной Markdown-ленты `published/screenshots/feed.md` со структурированными эпизодами сцен, прямыми ссылками на оригиналы в GitHub и превью ключевых кадров.
2. Сериализовать `published/screenshots/annotations.jsonl` в строгом соответствии с контрактом.
3. Интегрировать процесс разметки в `tools/publisher.py` внутри шага публикации скриншотов с полной изоляцией ошибок (try-except с сохранением основной публикации при сбое разметки).
4. Добавить команду CLI `python -m tools.campaign annotate-screenshots` и флаги в `publish`.
5. Покрыть функционал модульными тестами и выполнить верификацию на реальных скриншотах кампании.

## Формат feed.md
```markdown
# Хронологическая визуальная лента Kenshi

- **Обновлено**: `2026-11-03T11:00:00Z`
- **Период выборки**: последние 7 суток
- **Всего скриншотов**: 338
- **Выявлено эпизодов/сцен**: 45

---

### Эпизод 1: Безродный (Кадры 1-3)

- **Временные ориентиры**: День 45, 12:40 (файлы с `10:11:52Z` по `10:14:22Z`)
- **Локация**: Безродный (Mongrel)
- **Участники**: Хот Лон, Бип, Стражник
- **Тип сцены**: Диалог
- **Описание**: Отряд вошел в ворота города Безродный в Туманных землях.
- **Диалоги**:
  > **Бип**: "Бип самый сильный мечник!"
- **Кадры сцены**:
  - [screenshot_105.jpg](screenshot_105.jpg) ([Raw](...))
  - [screenshot_106.jpg](screenshot_106.jpg) ([Raw](...))
  - [screenshot_107.jpg](screenshot_107.jpg) ([Raw](...))

![screenshot_105.jpg](screenshot_105.jpg)

---
```

## Критерии приёмки
1. Прогон `python -m unittest discover -s tests` успешен.
2. `annotations.jsonl` и `feed.md` генерируются корректно.
3. Валидация публикации `validate_publication` подтверждает корректность пакета и отсутствие персональных данных.
4. Идемпотентность: повторный запуск без новых скриншотов не пересоздает и не перезапрашивает разметку.
