# Задача 02: Дедупликация и кластеризация кадров по сценам

## Цель
Реализовать эффективный автономный модуль `tools/screenshot_clustering.py` для:
1. Выявления точных дубликатов по SHA-256.
2. Вычисления перцептивных хэшей кадров (dHash / difference hash) с оптимизированным чтением.
3. Кластеризации последовательных кадров одной сцены в эпизоды (`scene_group_id`).

## Требования
1. **Точные дубли**:
   - Если два файла имеют идентичный SHA-256 (или идентичные байты):
     - Первый кадр считается первичным представителем (`is_exact_duplicate = False`).
     - Последующие помечаются `is_exact_duplicate = True`, `duplicate_of = <sha256_primary>`.
2. **Алгоритм разностного хэша (dHash)**:
   - Использование `av` + `numpy` при наличии, либо чистого Python декодера для легковесного чтения заголовков / downsampled сетки 9x8.
   - Сравнение интенсивности соседних пикселей по горизонтали: $P(x, y) > P(x+1, y)$ формирует 64 бита хэша.
   - Расстояние Хэмминга $H(hash_1, hash_2)$ измеряет визуальное отличие.
3. **Кластеризация в сцены (эпизоды)**:
   - Вход: упорядоченный по времени список скриншотов.
   - Правило границы эпизода:
     - Новый эпизод начинается, если временной интервал между соседними кадрами $\Delta t > 120$ секунд (2 минуты),
     - ИЛИ расстояние Хэмминга перцептивного хэша $H > 14$ (резкая смена плана/локации).
   - Каждому эпизоду присваивается стабильный идентификатор `ep_<index>_<short_hash>`.
   - Внутри эпизода сохраняются все кадры, но помечаются как принадлежащие одной сцене.
