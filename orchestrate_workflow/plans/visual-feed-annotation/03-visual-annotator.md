# Задача 03: Движок визуальной разметки скриншотов

## Цель
Реализовать модуль `tools/screenshot_annotator.py`, обеспечивающий извлечение текста интерфейса (OCR) и смысловую разметку кадров:
1. Кэширование аннотаций по SHA-256 (персистентный кэш, предотвращающий повторные затраты на неизмененные кадры).
2. Интеграция с Gemini 2.5 Flash через стандартный REST API (без внешних тяжелых библиотек) с передачей миниатюры или сжатого изображения в base64.
3. Надежный автономный эвристический fallback (при отсутствии `GEMINI_API_KEY`, сбоях сети или исчерпании лимитов 429).
4. Оптимизация обработки: для сцен из похожих кадров размечается ключевой кадр, а сопутствующие кадры анализируются на предмет изменений текста/диалогов.

## Архитектура аннотатора
1. **Кэш аннотаций**:
   - Чтение существующего `published/screenshots/annotations.jsonl` или локального файла кэша.
   - Если хэш SHA-256 скриншота найден в кэше — аннотация переиспользуется моментально (`provenance.source = "cache"`).
2. **Gemini 2.5 Flash клиент**:
   - Эндпоинт: `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key={GEMINI_API_KEY}`.
   - Формат запроса: structured JSON response (schema-guided output или строгий JSON prompt) для извлечения:
     - `game_day`, `game_time` (из нижнего правого угла интерфейса Kenshi).
     - `location` (название города, биома, зоны).
     - `characters` (имена персонажей игрока и видимых NPC).
     - `dialogues` (реплики в speech bubbles).
     - `notifications` (сообщения в левом нижнем/верхнем углу).
     - `scene_type`, `environment`, `actions`, `summary`.
   - Входное изображение оптимизируется по размеру (resize до 1280px по длинной стороне) для экономии токенов и ускорения ответа.
3. **Локальный эвристический fallback**:
   - При недоступности Gemini API формирует корректную разметку на основе метаданных, временных интервалов и контекста снимка кампании (если передан current snapshot: состав отряда, день, локация).
   - Позволяет конвейеру работать на 100% автономно без подключения к интернету.
