## Риски

- OAuth требует `credentials.json` клиента Google Cloud и согласия пользователя; агент секреты не вводит; токен хранится вне репозитория.
- Смена `file_id` при конвертации или импорте (создание нового файла вместо замены) разрывает привязку источников блокнота; проверяется на этапе 0.
- Потери форматирования Markdown → Doc → Markdown (таблицы, экранирование, ссылки, списки); граница допустимого определяется отчётом этапа 0.
- Новые зависимости (`google-api-python-client`, `google-auth-oauthlib`) в проекте без тяжёлых зависимостей; фиксируются и документируются.
- Лимит 50 источников блокнота: Doc и Sheet считаются источниками как файлы.
- Gemini может создавать новый документ вместо перезаписи — проверяет пользователь до этапа 2.
- Push в `main` из `gdrive-pull` (по умолчанию) затрагивает основное хранилище; смягчается защитами и `--accept`.
