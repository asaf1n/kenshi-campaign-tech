# 06-unit-reference

## Цель

В `published/tables/` публикуются технические данные для справочника юнитов (без вычисленных оценок): шаблоны персонажей по фракциям, составы отрядов и патрулей с регионами появления, отношения фракций между собой и настройки враждебности, если они хранятся в данных. Один CSV на таблицу, словарь колонок — в `tables/index.md`; число файлов учитывается в лимите источников игрового блокнота (профиль Диска расширяется только при согласии пользователя).

## Решения (пользователь, 2026-11-06)

- Шаблоны персонажей по фракциям: раса, диапазоны навыков и атрибутов, списки оружия и брони с грейдами.
- Составы отрядов и патрулей (шаблоны squad), регионы появления (homeless spawns по зонам).
- Отношения фракций между собой и настройки враждебности (по расе, полу, протезам), если есть в данных.
- Без вычисленных оценок.

## Этапы

1. Разведка форматов gamedata (character, squad/спавн-таблицы, faction relations, hostility): таблица «поле → запись → пример». Готово: список находимого и не находимого; не находимое не публикуется. Не начат.
2. Извлечение и CSV (`unit_templates.csv`, `squad_templates.csv`, `squad_spawns.csv`, `faction_relations.csv`, `faction_hostility.csv` — состав уточняется разведкой), словарь колонок. Готово: детерминированный вывод, тесты ≤ 3 на функцию, проверки проекта. Не начат.
3. Подсчёт числа файлов `tables/` и согласование с лимитом профиля Диска. Не начат.
