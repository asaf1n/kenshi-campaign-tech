## Дополнения к документации (решения пользователя 2026-11-07)

- `docs/data-contract.md`: значения `calc_*` публикуются без округления; совпадение с карточкой игры — равенство после округления до точности интерфейса; параметры шаблонов берутся после применения модов; `calc_*` заполняются только для подтверждённых карточками сочетаний (броня: класс × материал, оружие: класс × производитель), колонка `calc_status` (verified / unverified_class / unknown_level / unknown_template) объясняет пустые значения; цены карточек с уровнем для оружия и брони не публикуются.
- `state_code` уникальных NPC: 0 — мёртв, 1 — жив и свободен, 2 — в плену (`Kenshi/fcs.def:1884-1885`).
- Правки `AGENTS.md` п. 8-9 уже внесены (published/ не коммитится, доставка через deliver-companion); README и docs описывают то же.
