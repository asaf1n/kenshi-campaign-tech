# 03-table-exports

## Цель

Конвейер публикует `published/tables/` (CSV и `index.md`), манифест и валидация знают об артефакте, `deliver-companion` и `sync-drive` доставляют файлы, число источников на Диске остаётся в пределах 50, повторный запуск даёт побайтово идентичные файлы.

## Решения

- 2026-11-05. Формат — CSV (UTF-8, LF, заголовок в первой строке, запятая, экранирование по RFC 4180, UTF-8 без BOM по решению пользователя; ручная проверка в Gemini Notebook, при искажении — BOM) и один `tables/index.md` со словарём колонок, `snapshot_id`, игровым временем и числом строк. JSON в таблицах не используется. Предложение.
- 2026-11-05. Состав: `squad.csv`, `equipment.csv`, `storage.csv`, `item_prices.csv`, `trade_modifiers.csv`, `unique_npcs.csv`, `town_overrides.csv`, `diplomacy.csv`, `world_reactions.csv`, `world_reaction_links.csv`, `index.md` — 11 файлов, вместе с `brief.md`, `squad.md`, `changes.md`, `screenshots/index.md`, `feed.md`, `screenshots_latest.pdf` на Диске около 17 и ещё до 4 JSON, если пользователь оставит (вопрос 1). Лимит 50 проверяется подсчётом файлов `published/` на Диске и `Campaign/**/*.md` (вопрос 2). Предложение.
- 2026-11-05. Строки: сортировка по ключу (`character_id`, `slot`, `building_key`, `item_sid`…), числа без локали, пустое значение — пустая ячейка, отсутствие источника — пустая ячейка и пометка в словаре. Идентификаторы (`ps:…`, `sid`, `faction_sid`) сохраняются, связи по имени не строятся (`AGENTS.md`, п. 4).
- 2026-11-05. Привязка на Диске: новые файлы входят в `SESSION_FILES`/список `sync_session` и пишутся `write_in_place`; файлы не переименовываются между выпусками (имена фиксированы), чтобы `file_id` сохранялся. Предложение.

## Этапы задачи

1. Модуль выгрузки. `tools/tables.py` (чистые функции «снимок + locations + справочники → строки») и запись в `publisher.py` в staging; поля манифеста `artifacts.tables_*` или один ключ `artifacts.tables` (с обновлением `contracts/manifest.schema.json` и `tools/validation.py`), проверка согласованности числа строк с `index.md`. Готово: публикация на фикстурах создаёт все 11 файлов; `check-schemas` проходит; повторная публикация даёт идентичные байты (`generated_at` вне таблиц). Не начат.
2. Содержание групп. Колонки: отряд — id, имя, раса, группа, регион, поселение, `resolution_status`, статусы, кровь, `hunger_raw`, потерянные конечности, протез (слот, имя, level, grade), 4 атрибута и все навыки; экипировка — персонаж, слот, предмет, `sid`, `grade`, `manufacturer`, тип, значения шаблона и множители грейда/производителя отдельными колонками (итоговые характеристики — только после сверки формулы с карточками игры на ≥ 3 предметах разных классов, иначе не публикуются); урон `cut`/`blunt`, `armour_penetration`, `human/animal/robot_damage_mult`, `attack_mod`, `defence_mod`, `indoors_mod`, вес; броня — покрытие зон, сопротивления, модификаторы навыков, `template_unshown`; склады — поселение, здание, контейнер, предмет, `sid`, количество, базовая цена; цены и коэффициенты — по итогам 02/этапа 1; состояние мира, дипломатия (`relation`, `trust`, `trust_neg`, без классов) и условия реакций (запись, тип, поля как в игре, ссылки со значением `v`, соединение с текущим `state_code` NPC без прогноза). Готово: на снимке 06:03 выполняются числа задания из задачи 04, кроме проверенных ранее отдельно; недоступные поля названы в `index.md`. Не начат.
3. Доставка в Kenshi-Compain. `deliver_companion.py`: `SYNCED_DIRS` += `tables`, `REQUIRED_ARTIFACTS` без изменений; `gdrive_sync.py`: файлы `tables/*` в списке сессии (шарды `current/`, `extended/` по-прежнему не на Диске), удаление не используется — устаревшие файлы таблиц на Диске не удаляются (`file_id`), состав фиксирован. Готово: `python -m unittest tests.test_gdrive_sync` проходит с добавленным случаем «повторная синхронизация не меняет `file_id`/содержимое и не пишет неизменные файлы»; деливери на временный каталог содержит `tables/`. Не начат.
4. Регрессия. Тесты (≤ 3 на функцию): табличный тест колонок и сортировки на мини-снимке (ловит дрейф схемы колонок и недетерминизм порядка), тест идемпотентной записи Диска, тест валидации (манифест ссылается на отсутствующую таблицу → ошибка). `run_evidence.py` расширяется проверкой наличия `tables/` в доказательном выпуске. Готово: `python -m unittest discover -s tests`, `python tests/run_evidence.py`, `python -m tools.campaign check-schemas`, `git diff --check` проходят. Не начат.

Зависимости: 02 (данные), 01 (схема и `brief.md`). Риски: ширина `squad.csv` (≈ 35 столбцов навыков и атрибутов), размер `world_reactions.csv` (≈ 580 записей реакций и их ссылки), тяжёлая публикация при пересборке индекса игры; изменения `contracts/manifest.schema.json` затрагивают чужой репозиторий-потребитель — совместимость вперёд (необязательный ключ) обязательна.


Доставка на Диск, allowlist и профили вынесены в [05-drive-profiles](05-drive-profiles.md); этап 3 здесь охватывает только `deliver-companion`.
