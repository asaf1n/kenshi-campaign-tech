# 04-publisher-and-e2e-ops

## Цель

Обновление release bundle `published/` для чат-ИИ моделей (LLM ассистентов) новыми геополитическими и производственными артефактами (состояние дипломатии и баз в `brief.md`, работы и боевые режимы в `squad.md`), сквозная интеграция в `tools.campaign pipeline`, расширение матрицы приёмки `docs/acceptance.md` и проведение доказательного e2e-прогона на реальном сохранении.

## Решения

- 2026-11-02. Bundle публикации дополняется артефактом геополитики (`diplomacy.md`) с таблицей отношений с фракциями, списком удерживаемых/уничтоженных мировых лидеров и статусом городов, а `brief.md` дополняется сводкой инфраструктуры и ключевых запасов баз.
- 2026-11-02. Все генерируемые артефакты Markdown и JSON детерминированно строятся через `tools/rendering.py` из проверенного снимка, ручное редактирование `published/` запрещено.
- 2026-11-02. Валидатор `tools/validation.py` гарантирует отсутствие локальных путей пользователя (`C:\Users\...`) и секретов в выходном пакете.
- 2026-11-02. Коммит и push обновлённого `published/` выполняются оркестратором по постоянному разрешению пользователя после успешной верификации по DoD.

## Этапы задачи

1. **Детерминированный рендеринг геополитики и баз**: Реализовать в `tools/rendering.py` генерацию `diplomacy.md` и секций баз для `brief.md`, зарегистрировать новые артефакты в `manifest.schema.json`. Готово: повторный рендер даёт побайтовое совпадение (100% детерминизм). Не начат.
2. **Сквозная интеграция конвейера**: Обновить `tools/pipeline.py` и CLI `tools/campaign.py` для бесшовного выполнения цепочки `extract → diff → validate → render → publish` на нативном движке без внешнего конвертера. Готово: команда `python -m tools.campaign pipeline` отрабатывает с кодом возврата 0. Не начат.
3. **Доказательный e2e-прогон и приёмка**: Выполнить сквозную проверку на реальном сохранении кампании, обновить матрицу приёмки `docs/acceptance.md` новыми критериями (дипломатия, уникальные NPC, базы), зафиксировать протокол evidence. Готово: `tests/run_evidence.py` успешен, все тесты и проверки схем зелёные. Не начат.
