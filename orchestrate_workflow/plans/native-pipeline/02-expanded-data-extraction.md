# 02-expanded-data-extraction

## Цель

Прямое извлечение подтверждённых новых категорий игровых данных из записей FCS без приближённых вычислений и эвристик: дипломатия фракций, статус ключевых NPC, динамика городов и World States, работы персонажей, переноска, награды и производственная инфраструктура баз.

## Решения

- 2026-11-02. Дипломатия: точные числовые значения отношений (-100.0..+100.0) и уровни доверия читаются напрямую из записей типа 37 в `quick.save` по устойчивым `sid` фракций, без нормализации по именам. При отсутствии связи relation сохраняется как null со standing "unknown" (без вымышленных нулей).
- 2026-11-02. Мировые фигуры и состояния: 79 записей `usedUniques` из типа 56 (`player: true/false` строго из секции bool, подтверждённое строковое состояние dead_or_captured только для проверенного кода state_code == 2) маппятся на устойчивые `sid` персонажей; переопределения городов (`replacementTown`) берутся из 554 записей типа 94 (потери населения pop/popd перенесены на этап 3).
- 2026-11-02. Работы и приказы: массивы `pjob` и `tjob` из типа 67 декодируются в имена через перечисление `taskType` из `fcs_enums.def` (289 типов задач) со ссылками на целевые объекты.
- 2026-11-02. Персонажи: добавление полей физической переноски (`target_handle`, `carried_by`), наград за голову (`bountyfac0..N`, `bountyexp0..N`, `crimes0..N`), боевых режимов (`taunt`, `passive`, `ranged`, `defensive`, `chase`, `stealth`, `non_combat`).
- 2026-11-02. Базы: извлечение готовности (`complete`), сырого прогресса стройматериалов (`construction_progress_raw`), питания (`power_on`), заряда аккумуляторов (`batterycharge`), реальных локализованных имен построек из `string.name` (отсекая технический инстанс `r["name"] == "0"`), узлов анимации (`usage_nodes`) и качественных свойств предметов в сундуках (грейды, качество, заряды, опциональные износ/урон, handle владельца).

## Этапы задачи

1. **Модуль извлечения геополитики и дипломатии**: Реализовать сбор `diplomacy` (отношения игрока и всех фракций) и `world_state` (статус уникальных лидеров + переопределения 9+ городов кампании). Готово: `test_diplomacy_extraction.py` верифицирует пленение Феникса, Короля Пыли и разрушение Бугристого Холма на реальном сейве. Выполнено 2026-11-02.
2. **Расширение извлечения персонажей**: Внедрить сбор `carrying`, `bounties`, боевых режимов и очереди назначенных работ (`jobs`). Готово: `test_character_jobs_and_carrying.py` подтверждает декодирование работ фермеров/медиков и переноску персонажей Хоббсом. Выполнено 2026-11-02.
3. **Модуль инфраструктуры и производства баз**: Извлечь состояние 157 построек (питание, аккумуляторы, стройка) и детальное содержимое складских контейнеров без потери грейдов экипировки. Готово: `test_base_production_extraction.py` подтверждает извлечение запасов пеньки, медикаментов и статуса станков. Выполнено 2026-11-02.
