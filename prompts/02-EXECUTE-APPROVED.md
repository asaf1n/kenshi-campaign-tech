# Задание агенту: выполнить утверждённый план Kenshi Campaign

Этот промпт применяется **после утверждения конкретного плана**, подготовленного по `prompts/01-START-AGENT.md`. Номер/имя плана, путь и версия рабочего дерева должны быть установлены из репозитория, а не угаданы.

1. Прочитай `AGENTS.md`, `orchestrate_workflow/method.md`, утверждённый `00_summary.md`, перечисленные им задачи, и установленный `orchestrate/SKILL.md` (если доступен). Сверь `git status`, HEAD, существующие чужие правки и подтверждённое состояние этапных сессий.
2. Выполняй этапы согласно реальному плану и протоколу глобальных навыков; не создавай альтернативных `spec/result/review` или копии ролей. Одна зона записи — один исполнитель; независимое ревью итоговой версии существенных контрактов и логики.
3. Сначала вертикальный срез на двух реальных сейвах: import → state → valid/invalid diff → validation → publish → краткая сводка. Переиспользуй текущий конвертер. Отсутствующие входы и среды фиксируй, не подменяй синтетикой.
4. Для каждой задачи сопоставь изменённые файлы и тесты с AC-01…AC-15. Проверь read-only исходников, стабильность identity, отсутствие ложного «0 изменений», ветки/reload, атомарность и отсутствие персональных путей в published.
5. Git-коммит принятого этапа выполняет orchestrator, если не действует запрет; push, создание remote, изменение прав доступа и секретов только с отдельного разрешения. Не перезаписывай не относящиеся к работе файлы.
6. Проверка интеграции ChatGPT: если разрешено, опубликуй безопасный bundle и проверь фактическое чтение `snapshot_id` в ChatGPT. Если это недоступно из агента, подготовь одну минимальную процедуру валидации пользователя и пометь AC-13 частично проверенным.
7. Финальный отчёт: список реализованных функций и exact commands, файлы, результаты тестов, версии форматов, доказательства на реальных сейвах, независимый reviewer verdict, непроверенные пункты, оставшиеся задачи и эксплуатационная команда обновления.

Не начинай до подтверждённого утверждения плана; если такого подтверждения нет — сообщи состояние и не выдавай планирование за реализацию.
